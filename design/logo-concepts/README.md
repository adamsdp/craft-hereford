# Logo concepts

Six alternative directions for the Craft Hereford logo. See `concepts-sheet.png` for them side by side.

| # | Concept | Idea |
|---|---|---|
| 1 | The Cabinet | The glass cabinet customers find in the café, with handmade pieces and a coffee. |
| 2 | Running Stitch | A bold H sewn together with running stitch, a knot and a needle. |
| 3 | Orchard | A stitched apple patch for Herefordshire's orchards and cider. |
| 4 | Black & White | Heritage badge with a timber-framed house like the county's black-and-white villages. |
| 5 | River Wye | Lettering-led, with a line of stitching flowing like the Wye. |
| 6 | Button | A sunny sewing button with chunky, friendly lettering. |

Each has a main logo (`N-name.svg`) and a small icon version (`N-name-icon.svg`) for profile pictures and browser tabs. All lettering is converted to shapes, so the files display correctly without fonts installed.

Fonts used (all free, Google Fonts): Fraunces, Outfit, Caveat, DM Serif Display, DM Sans, Alegreya SC, Nunito.
